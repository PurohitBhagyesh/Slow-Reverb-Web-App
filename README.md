🎵 Slowed + Reverb Studio

A browser-based audio studio for creating aesthetic slowed + reverb and lo-fi versions of music.

## 🔗 Links

[🌐 **Open Live App**](https://slowreverb.netlify.app)

[📥 **Download Source Code**](https://github.com/PurohitBhagyesh/SlowReverb/archive/refs/heads/main.zip)
⸻

✨ Features

* 🐌 Slow down audio
* 🎚️ Pitch manipulation
* 🌊 Stereo algorithmic reverb
* ⏱️ Pre-delay control
* 🏛️ Decay / room-size control
* 📻 Low-pass filter
* 🔊 808 bass boost
* 🎧 Real-time preview
* 📊 Audio spectrum visualization
* 🔮 Aesthetic presets
* 💾 16-bit Stereo PCM WAV export
* 🔒 100% client-side processing

🎵 Supported Audio

Input

* MP3
* WAV
* FLAC
* M4A
* OGG
* AAC

Output

WAV — 16-bit Stereo PCM

The processed audio can be downloaded directly as a WAV file.

🔮 Presets

* 🌙 Classic Slowed
* 🏎️ Midnight Drive
* 🌌 Spaced Out
* 🌧️ Bedroom Muffled
* ☕ Lo-Fi Chill
* 📼 Chopped & Screwed

🎛️ Audio Processing

The app provides controls for:

* Speed / pitch
* Wet / dry reverb
* Decay / room size
* Pre-delay
* Low-pass filtering
* 808 bass boost

🔒 Privacy

Audio processing happens directly in the browser. Your audio does not need to be uploaded to a server for processing.
